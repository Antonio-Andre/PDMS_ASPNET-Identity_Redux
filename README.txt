# PDMS - Standalone Frontend (Mock Version)

Frontend interface for the PDMS back-office management system. This branch runs entirely on the client side using mocked data, with no dependency on the .NET API or database.

## Features
- UI for warehouse management, fleet status, and order tracking
- Global state management with Redux Toolkit (RTK)
- Standalone execution without backend requirements

## Tech Stack
- React
- Redux Toolkit
- JavaScript / TypeScript

## How to Run

1. Run locally:
   ```bash
   cd PDMS_React_RTK
   npm install
   npm run start
